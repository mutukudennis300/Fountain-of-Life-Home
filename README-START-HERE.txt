FOUNTAIN OF LIFE CHILDREN'S HOME — UPDATED WEBSITE
==================================================

START HERE
----------
1. Extract the entire ZIP into a folder on your computer.
2. Open index.html in a browser to preview the homepage.
3. Test all pages by clicking the site navigation and footer links.
4. Upload the CONTENTS of this folder to your GitHub Pages repository root (not the enclosing folder).
5. Keep the filenames and folder names unchanged; this site uses names such as "About.html" and "Programs and Services.html".

DESIGN
------
The homepage uses css/home.css. The existing inner pages keep their page-specific CSS and load css/refresh.css after it for the shared forest-green, warm-cream and restrained-gold brand system. Original brand colours (#1F51FF, #39FF14, #FFF01F) appear only as small accents.
